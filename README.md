# ニコる記録帳

ニコられた自分のコメントを記録・閲覧する、私用の Chrome 拡張。

- **月別**: コメント投稿月ごとに、9 ニコる以上のコメントを一覧表示する
- **ランキング**: ニコられたコメント全体をニコる数の多い順に並べる（検索・削除済み除外つき）
- **自動更新**: 6 時間ごと＋Chrome 起動時に差分を取得する。画面の「今すぐ更新」で手動更新もできる

## インストール

1. `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ
3. ツールバーの拡張アイコンを押すと記録帳が開く。インストール直後に初回の全件取得が自動で始まる（約 1〜2 分）

nicovideo.jp にログインした状態の Chrome で使うこと。拡張から直接取得できない場合は、開いている nicovideo.jp タブを経由して取得する。

## 仕組みと制約

- データ元はニコニコの非公開 API `nvapi.nicovideo.jp/v1/users/me/nicoru/receive`（ニコられた履歴）。仕様変更で動かなくなる可能性がある
- 履歴は「1 ニコる = 1 件」なので、コメント（動画 ID・再生位置・投稿日時）単位で集約し、最大ニコる数を記録している
- 一度もニコられていないコメントは API に現れないため、ランキングの対象外
- データは `chrome.storage.local` にのみ保存し、外部へは送信しない
